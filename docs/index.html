What this model assumes

Demand / dispatch decoupling. The tariff-independent layer (base load + heat pump from heating-degree-days + solar from a clear-sky envelope + EV daily kWh) is fixed across every tariff comparison. Only the dispatch — when to draw from grid, when to charge EV, when to cycle the battery — changes per tariff. This is what makes the comparison honest; historic smart-meter data would already be tariff-shifted by your old battery/EV schedule.

Dispatch. Per day, slots below the 35th percentile price are "cheap-tier": battery charges to capacity at max rate, EV fills its daily kWh need from cheapest slots first. In non-cheap slots the battery discharges to cover residual load. Solar always serves load first, then surplus charges battery, then exports.

Tariff rates are mid-2024 approximations. For accurate £ figures use the Python CLI (tarriftool fetch-rates) to pull live Octopus rates; this browser build is for scenario exploration. Standing charges are flat 50p/day; export rate flat 15p/kWh.

Limitations. No Agile half-hourly real prices (uses a sinusoidal proxy); HP can't pre-heat into cheap windows independently of battery; UK weather is a smooth sinusoid (no cold-snap variability); no DST/leap-year handling.
